¿Cómo funciona?

El bot recibe mensajes de WhatsApp, identifica el producto que busca el cliente, busca el precio en la base de datos y responde automáticamente.

El bot solo responde precio y disponibilidad. El vendedor continúa la conversación para cerrar la venta, coordinar entrega y facturar.

Instrucciones para iniciar el bot

  1. Haz doble clic en INICIAR-BOT.bat en la carpeta del proyecto
  2. Espera a que aparezca el código QR (en la terminal o aquí arriba)
  3. Abre WhatsApp → Dispositivos vinculados → Vincular dispositivo
  4. Escanea el código QR
  5. ¡Listo! El bot comenzará a responder automáticamente
